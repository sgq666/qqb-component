# API 接口测试工具使用说明

## 功能介绍

API 接口测试工具是一个用于测试后端接口的页面，用户可以输入接口路径、请求方法、请求头和请求参数，然后发送请求并查看响应结果。

## 访问方式

在浏览器中访问 `/api-tester` 路径即可打开 API 测试页面，例如：
```
http://localhost:3000/#/api-tester
```

## 使用方法

1. **接口路径**：输入要测试的接口 URL 路径，例如 `/api/users` 或完整的 URL

2. **请求方法**：选择 HTTP 请求方法（GET、POST、PUT、DELETE、PATCH）

3. **跨域处理**：
   - 勾选"处理跨域问题（使用特殊配置发送请求）"选项可以使用特殊配置发送请求，以减少跨域问题

4. **请求头**：
   - 点击 "+ 添加请求头" 按钮添加请求头
   - 输入请求头的键和值
   - 可以添加多个请求头
   - 点击"删除"按钮可以移除不需要的请求头

5. **请求参数**：
   - 在文本框中输入 JSON 格式的请求参数
   - 例如：`{ "name": "张三", "age": 25 }`
   - 对于 GET 请求，参数会作为查询参数发送
   - 对于 POST/PUT 等请求，参数会作为请求体发送

6. **发送请求**：
   - 点击"发送请求"按钮发送请求
   - 请求结果会显示在下方的"响应结果"区域

## 跨域问题解决方案

如果在测试接口时遇到跨域问题，可以尝试以下方法：

1. **使用特殊配置发送请求**：
   - 勾选"处理跨域问题（使用特殊配置发送请求）"选项
   - 这将使用 fetch API 直接发送请求，并设置以下配置：
     - `mode: 'cors'` - 启用 CORS 模式
     - `credentials: 'omit'` - 不发送凭据，避免跨域问题

2. **检查后端 CORS 配置**：
   - 确保后端正确配置了 CORS 策略
   - 允许来自前端域名的请求

## 重要说明

由于浏览器安全机制，某些请求头（如 Referer、Origin 等）无法通过前端代码完全移除，它们是由浏览器自动添加的。因此，解决跨域问题的最佳方式是：

1. 确保后端正确配置 CORS 策略
2. 使用"处理跨域问题"选项，通过特殊配置减少跨域问题
3. 在开发环境中，可以考虑使用代理服务器来避免跨域问题

## 注意事项

1. 请求参数必须是有效的 JSON 格式
2. 如果请求失败，错误信息会显示在响应结果区域
3. 该工具使用项目中配置的 [requestService](file:///d:/code/front/qqb-component/my-app/src/services/requestService.ts#L15-L229) 发送请求，会自动处理认证和解密等逻辑
4. 响应结果会以格式化的 JSON 形式显示
5. 当勾选"处理跨域问题"选项时，将使用 fetch API 直接发送请求，绕过 axios 和 requestService
