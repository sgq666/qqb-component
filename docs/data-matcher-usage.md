# 数据匹配工具 - 智能文本匹配与数据对比系统

## 功能介绍

数据匹配工具是一个智能文本匹配系统，用于比对两个数据集：
- 数组A：字符串数组或包含name和code字段的对象数组
- 数组B：包含name和code字段的对象数组

工具会根据以下规则进行匹配：
1. **Code精确匹配**：如果数组A中的元素包含code字段，则直接使用code与数组B的code进行精确匹配
2. **文本相似度匹配**：如果code未匹配到数据或数组A元素没有code字段，则使用文本相似度算法匹配数组A的name与数组B的name

完全匹配的项会自动匹配，相似度较高的项会推荐给用户手动确认。

## 数据持久化功能

为了防止意外刷新页面导致工作进度丢失，工具提供了数据持久化功能：
- 自动将匹配结果保存到浏览器本地存储（localStorage）
- 页面刷新后自动恢复之前的匹配进度
- 提供"清除缓存"按钮手动清除保存的数据

### 工作原理
1. 每次匹配结果发生变化时，自动保存到浏览器本地存储
2. 页面加载时自动检查是否存在保存的匹配结果
3. 如果存在保存的数据，会提示用户并自动恢复进度
4. 用户可以随时点击"清除缓存"按钮清除保存的数据

### 注意事项
- 数据仅保存在当前浏览器中，更换浏览器或清除浏览器数据会丢失进度
- 保存的数据会在重新开始匹配任务时被覆盖
- 建议在完成匹配任务后及时导出结果，以防数据丢失

## 匹配结果查看功能

工具提供了便捷的匹配结果查看功能：
- **已匹配数据查看**：可以查看所有已完成匹配的数据项，包括自动匹配和手动匹配
- **未匹配数据查看**：可以查看所有待处理的数据项，并支持跳转到指定项进行手动匹配
- **匹配统计**：显示详细的匹配统计信息，包括总数、自动匹配数、手动匹配数和待处理数

### 已匹配数据详细功能
已匹配数据支持以下高级功能：
- **分页展示**：避免一次性加载大量数据影响性能
- **搜索功能**：支持按数组A或数组B的值进行搜索
- **类型筛选**：可以筛选不同类型的匹配结果：
  - **Code匹配**：通过code字段精确匹配的数据
  - **Name匹配**：通过name字段精确匹配的数据
  - **手动匹配**：用户手动选择的匹配数据

### 未匹配数据详细功能
未匹配数据同样支持分页展示和搜索功能：
- **分页展示**：避免一次性加载大量未匹配数据
- **搜索功能**：支持按数组A的值进行搜索
- **手动匹配**：可以点击"手动匹配"按钮跳转到指定项进行匹配

## 高级匹配设置

工具支持高级匹配设置，可以优化匹配结果：

### 字段权重设置
- 可以设置只匹配前x个字段，提高匹配精确度
- 支持设置权重百分比，控制前x个字段在匹配中的重要性
- 当权重设置为100%时，只考虑前x个字段进行匹配
- 当权重设置为0%时，只考虑完整字段进行匹配

## 懒加载推荐匹配项

在手动匹配过程中，系统默认显示前5个最相似的推荐匹配项。如果需要查看更多推荐项，可以点击"加载更多推荐项"按钮，系统会懒加载后续的匹配项，提升用户体验。

## 使用方法

### 1. 数据输入

#### 方式一：JSON格式输入
- 在左侧文本框中输入数组A的JSON格式数据：
  - 字符串数组：`["张三", "李四", "王五"]`
  - 对象数组：`[{"name": "张三", "code": "001"}, {"name": "李四", "code": "002"}]`
- 在右侧文本框中输入数组B的JSON格式数据：
  ```json
  [
    {"name": "张三", "code": "001"},
    {"name": "李四", "code": "002"},
    {"name": "王五", "code": "003"}
  ]
  ```

#### 方式二：Excel文件上传
- 点击"上传Excel文件"按钮上传Excel文件
- 数组A的Excel文件应包含name列，可选code列
- 数组B的Excel文件应包含name和code两列数据

### 2. 开始匹配

点击"开始匹配"按钮，系统会自动进行以下处理：
1. 首先使用code字段进行精确匹配（如果数组A元素包含code）
2. 对于未匹配的项，使用文本相似度算法进行匹配
3. 自动匹配完全相同的项
4. 对于不完全匹配的项，推荐最相似的匹配项

### 3. 手动匹配

对于系统无法自动匹配的项，用户需要：
1. 查看系统推荐的匹配项（按相似度排序）
2. 从下拉列表中选择最合适的匹配项
3. 如果没有合适的匹配项，可以选择"不匹配"

### 4. 导出结果

匹配完成后，可以导出结果：
- **导出Excel**：将匹配结果导出为Excel文件
- **导出JSON**：将匹配结果导出为JSON文件，包含以下字段：
  - `aCode`：数组A元素的code（如果存在）
  - `aName`：数组A元素的name
  - `bCode`：数组B元素的code（如果匹配成功）
  - `bName`：数组B元素的name（如果匹配成功）
  - `score`：匹配相似度分数（0-1之间）

## 算法说明

### 相似度计算
- 完全相同的文本：相似度为1.0
- 使用Levenshtein距离算法计算相似度
- 相似度范围：0.0-1.0，1.0表示完全相同

### 匹配流程
1. 优先使用code字段进行精确匹配
2. 未匹配的项使用文本相似度算法匹配
3. 自动匹配完全相同的项
4. 推荐相似度最高的候选匹配项
5. 用户手动确认匹配关系

## 性能优化

- 对于大量数据（上千条），采用分批处理避免界面冻结
- 对于超长字符串，使用简化算法提高计算速度
- 推荐列表只显示前10个最相似的匹配项

## 注意事项

1. 数组A和数组B都支持上千条数据的处理
2. Excel文件上传时，系统会自动识别name和code列
3. 匹配过程可能需要一些时间，请耐心等待
4. 导出的文件包含完整的匹配结果和相似度信息
