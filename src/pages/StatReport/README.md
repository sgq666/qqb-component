# 统计报表功能说明

## 功能概述
这是一个用于处理统计报表的页面，支持上传Excel文件并导出处理后的数据。该功能还支持部门树形结构展示和选择，可以按部门层级生成报表。

## 页面说明

### 1. 统计报表 (/stat-report)
通用统计报表页面，支持上传Excel文件并按部门树结构筛选导出。

### 2. 部门日报统计报表 (/day-count-report)
基于dayCount.txt数据生成的部门日报统计报表，数据格式为：
- date: 日期
- deptCode: 部门代码
- deptDayCount: 部门在当天完成任务的数量

该页面会自动加载dayCount.txt和dept.txt数据，处理后导出到excel/test1.xlsx模板。

### 3. 高级部门日报统计报表 (/advanced-day-count-report)
增强版的部门日报统计报表，支持：
- 部门树形结构选择（支持多选）
- 多工作簿Excel导出（每个工作簿名称为部门的第二级名称）
- 用户可自定义报表标题
- 根据用户选择的部门构建报表数据

### 4. Excel模板生成器 (/excel-template-generator)
根据用户选择的部门生成符合规范的Excel模板，支持：
- 部门树形结构选择（支持多选）
- 生成符合规范的Excel模板
- 用户可自定义报表标题

## 使用方法（统计报表）

1. 页面加载时会自动加载默认的部门树结构（来自dept.txt文件）
2. 点击"上传Excel文件"按钮选择Excel文件
3. 在左侧部门树中勾选需要统计的部门（支持多选）
4. 系统会自动展示数据
5. 点击"导出Excel"按钮将数据导出为新的Excel文件（仅导出选中部门的数据）

## 使用方法（部门日报统计报表）

1. 页面加载时会自动加载dayCount.txt和dept.txt数据
2. 系统会自动处理数据并展示报表
3. 点击"导出Excel"按钮将数据导出到excel/test1.xlsx模板

## 使用方法（高级部门日报统计报表）

1. 页面加载时会自动加载dayCount.txt和dept.txt数据
2. 在左侧部门树中勾选需要统计的部门（支持多选）
3. 系统会自动展示数据
4. 输入自定义报表标题（可选）
5. 点击"导出Excel"按钮将数据导出为多工作簿Excel文件

## 使用方法（Excel模板生成器）

1. 页面加载时会自动加载dayCount.txt和dept.txt数据
2. 在左侧部门树中勾选需要生成模板的部门（支持多选）
3. 系统会自动展示数据
4. 输入自定义报表标题（可选）
5. 点击"生成Excel模板"按钮生成符合规范的Excel模板

## 数据格式要求

### 上传的Excel文件应包含以下列：
- 部门名称 (deptName)
- 销售额 (salesAmount)
- 完成率 (completionRate)
- 日期 (date)
- 部门代码 (deptCode) - 用于与部门树关联

### dayCount.txt数据格式：
```json
[
  {
    "date": "2025-11-12",
    "deptCode": "469005870000",
    "deptDayCount": "1"
  },
  // ...
]
```

### 部门文件格式：
- dept.txt 文件应包含JSON格式的部门数组
- 每个部门对象应包含 deptCode、deptName 和 parentCode 字段

## 功能特点

- 默认展示dept.txt的树形结构
- 支持从后台接口加载部门数据（预留功能）
- 树形部门结构展示
- 支持部门多选
- 按选中部门层级导出数据
- Excel文件导入导出
- 支持dayCount.txt数据处理和模板导出
- 支持多工作簿Excel导出
- 支持自定义报表标题
- 支持生成符合规范的Excel模板

## 操作说明

- **重新加载默认部门树**：点击此按钮重新加载public目录下的dept.txt文件
- **从接口加载**：点击此按钮可以从后台接口加载部门数据（当前为模拟数据）
- **部门选择**：在左侧部门树中勾选需要统计的部门，支持多选
- **数据导出**：导出时会自动包含选中部门及其所有子部门的数据
